# Deal Forge

Analyze flips, wholesale contracts, pallet lots, and service jobs. Get a max offer, profit, ROI, and a go / no-go. Save deals to a local pipeline board.

Live after GitHub Pages is on: https://bet34.github.io/deal-forge-website/

## What this version adds

- Working 4-type deal analyzer (not a static mock)
- Pipeline board with status moves, stored in the browser
- Mobile nav, waitlist form, FAQ, SEO meta + JSON-LD
- Single-file site. No build step.

## Enable GitHub Pages

1. Open https://github.com/Bet34/deal-forge-website/settings/pages
2. Source: Deploy from a branch
3. Branch: `main` / root
4. Save. Site is live in a few minutes.

## Local preview

Open `index.html` in a browser. That is the whole app.
