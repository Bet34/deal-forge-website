# Deal Forge

Live site: https://bet34.github.io/deal-forge-website/

Browser tool for flips, wholesale, rentals, pallet lots, and service jobs.

- Max offer + 0–100 deal score
- Hard kill rules and watch warnings
- Repair contingency pad on flips and wholesale
- Cash to close, break-even sell, profit per day
- Offer ladder: open (92%), target, walk
- Base vs +10% haircut check
- Michigan close-cost fill on flips (transfer tax + title, no agent fee)
- Short text you can copy and send
- Seller asking vs max, with room or overage bar
- 70% rule check and annualized flip ROI
- Stress haircut on ARV, rent, or sell price
- Downriver presets (Taylor flip, wholesale, returns lot, furnace job, Southgate rental)
- Copy-ready offer letter, ladder, and share link
- Pipeline with stage filter, sort, age, stale flag, duplicate, compare top two
- Closed profit on the board
- JSON import + export, CSV export

Data stays in the browser. Not financial advice. Michigan close fill uses $4.30 per $500 (state $3.75 + typical county $0.55). Confirm the county before you wire.
