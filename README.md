# Deal Forge

Live site: https://bet34.github.io/deal-forge-website/

Browser tool for flips, wholesale, rentals, pallet lots, and service jobs.

- Max offer + 0–100 deal score
- Seller asking vs your max, with room or overage
- 70% rule check and annualized flip ROI
- Stress haircut on ARV, rent, or sell price
- Copy-ready offer letter and share link
- Notes and next move on the local pipeline
- JSON import + export, CSV export

Data stays in the browser. Not financial advice.

## Deploy

Repo Settings → Pages → Deploy from branch → `main` / root.
